# Небольшие проверки модели

Скрипт `explore.py` сравнивает логистическую регрессию на трёх разделениях
встроенного набора Digits. Он обучает модель на train и считает accuracy и macro-F1
только на validation. Отложенный test каждого разделения не используется.

```bash
python -m pip install -r requirements.txt
python explore.py
python explore.py --seeds 3 9 15 --c 0.5
python -m unittest discover -s tests -v
```

Результат исходного запуска (`C=1.0`):

| Seed | Validation accuracy | Validation macro-F1 |
|---:|---:|---:|
| 7 | 0.9694 | 0.9694 |
| 21 | 0.9667 | 0.9668 |
| 42 | 0.9722 | 0.9724 |

Попробуй изменить `--c` и посмотреть, как различаются результаты между
разделениями. Каждый seed заново распределяет объекты между выборками, поэтому
изменение числа не измеряет улучшение модели само по себе. Не выбирай параметры
по опубликованному test из `reports/metrics.json`: он уже просмотрен.

`explore.py` не сохраняет модель и не заменяет полный цикл в `digit_vision/train.py`.
Показатели относятся к изображениям 8×8 из этого датасета, а не к собственным
фотографиям цифр.
