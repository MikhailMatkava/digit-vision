# Как разобраться в проекте перед собеседованием

## Порядок работы

1. Выполни команды из README и открой отчёт с ошибками.
2. Пройди data.py: проверь формы (N, 64), диапазон яркостей и индексы split.
3. Пройди train.py: найди места fit/predict и объясни, какие данные доступны каждому fit.
4. Нарисуй свою цифру, запусти predict.py, попробуй --invert. Зафиксируй результат,
   даже если он неверный, и объясни отличие входа от обучающих примеров.
5. Сделай собственное улучшение отдельным коммитом и опиши, что измерил.

## Вопросы, на которые стоит уметь отвечать

**Почему не сразу нейросеть?** Это небольшой baseline, быстрый на CPU.
Он помогает отладить данные и протокол оценки. CNN здесь ещё не реализована;
без эксперимента нельзя утверждать, что она лучше или хуже SVM.

**Почему три выборки?** Train используется для fit, validation — для выбора
между кандидатами, test — только для итогового измерения.

**Почему scaler в Pipeline?** Если оценить mean/std по всему набору до разбиения,
статистика test попадёт в обучение. Pipeline fit вычисляет их только по переданным данным.

**Почему после выбора можно обучаться на train + validation?** Конфигурация уже
зафиксирована; дополнительные размеченные данные используются для финальной модели.
Тестовая выборка всё ещё не участвует в fit.

**Что даёт macro-F1?** Среднее F1 по классам с одинаковым весом каждого класса.
Accuracy считает долю верных ответов по всем объектам. Датасет близок к сбалансированному,
но per-class отчёт всё равно полезен.

**Почему seed не доказывает надёжность?** Он делает split повторяемым, но одна
случайная выборка не оценивает разброс метрик и перенос на другие условия.

**Почему нет confidence?** SVM decision score не является вероятностью.
Для вероятностной уверенности нужна отдельная калибровка и проверка её качества.

**Что теряется при flatten?** Пиксели остаются на фиксированных позициях, но
модель не получает встроенную свёрточную структуру и совместное использование весов.

## Первый самостоятельный эксперимент

Собери 30–50 собственных изображений с известными метками, сохрани исходные файлы
и список меток. Не включай их в обучение. Сравни accuracy на них с исходным test,
покажи ошибки. Если потом используешь эти картинки для доработки preprocessing,
считай их validation и собери новый независимый test.
